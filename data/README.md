# کاتالوگ محصولات

منبع واحد اطلاعات فروشگاه در `products.json` نگهداری می‌شود. آرایه‌ی فعلی باید دقیقاً ۷۰ محصول داشته باشد؛ برای افزودن یا ویرایش محصول، رکوردهای همین فایل را تغییر دهید و `python3 scripts/validate_product_catalog.py` را اجرا کنید.

## فیلدهای مهم

- `id`, `sku`, `slug`: شناسه‌های یکتا برای صفحه و مدیریت محصول.
- `name`, `brand`, `model`, `category`, `cat`, `kind`: هویت و طبقه‌بندی کالا.
- `short_description`, `description`, `specifications`: توضیحات و مشخصات برگرفته از منبع محصول.
- `price`: عدد به **تومان**؛ اگر قیمت جاری قابل‌تأیید نیست، `null` بماند تا فروشگاه «قیمت به‌زودی» نمایش دهد.
- `currency`: برای قیمت‌های محلی `TOMAN` و برای ارزش اسمی کدهای منطقه‌ای `USD`.
- `source`, `source_url`: منبع قیمت در صورت قیمت‌گذاری، یا صفحه‌ی رسمیِ مرجع وقتی قیمت تأیید نشده است. `price_source_url` فقط برای قیمت تأییدشده پر شود.
- `spec_source_url`, `image_source_url`, `checked_at`: ردیابی مشخصات، تصویر و تاریخ بررسی.
- `stock`: تعداد موجودی؛ تا زمان تأیید انبار `null` بماند. `status` و `market_availability` وضعیت فهرست/بازار را جداگانه توصیف می‌کنند.
- `images`: تصویر محلی در `assets/catalog/` ترجیح دارد؛ لینک تصویر مستقیم رسمی هم مجاز است.
- `region`, `edition`, `platforms`, `warranty`, `box_contents`: برای تفاوت SKUها، ریجن و نسخه‌ها.

قیمت تخفیفی فقط وقتی وارد شود که قیمت قبل از تخفیف هم از منبع قابل‌بررسی تأیید شده باشد. تصویر یا مشخصات یک SKU را به مدل دیگری تعمیم ندهید.
